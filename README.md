# MarineLife

MarineLife is a JavaFX user interface project about marine animals and plants. 
It includes a splash screen, login screen, and landing page with images and CSS styling.

## Built with

- Java
- JavaFX and FXML using Scene Builder
- CSS
- Maven

## Run the project

Open the project in IntelliJ IDEA and run `MarineLifeApplication` or 'Launcher'
